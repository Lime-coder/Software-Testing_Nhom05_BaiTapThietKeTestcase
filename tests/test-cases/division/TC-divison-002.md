# TC-DIV-002: Divide integers with a fractional result

## Requirement ID
FR-DIV-001

## Module / Test type / Technique
Division / Functional / Equivalence Partitioning

## Preconditions
- The application is open and ready to accept numeric input.

## Test Owner
Quốc Huy

## Test data
| Numerator | Denominator |
|---|---|
| 7 | 2 |

## Test steps
1. Enter `7` as the numerator.
2. Select the division operation.
3. Enter `2` as the denominator.
4. Submit the calculation.

## Expected result
The application displays the result `3.5` without rounding or truncating it to an integer.

## Status / Related bugs
Not Run / None
