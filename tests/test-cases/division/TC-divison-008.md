# TC-DIV-008: Divide decimal numbers

## Requirement ID
FR-DIV-001

## Module / Test type / Technique
Division / Functional / Equivalence Partitioning

## Preconditions
- The application is open and ready to accept numeric input.
- The application accepts decimal numbers.

## Test Owner
Quốc Huy

## Test data
| Numerator | Denominator |
|---|---|
| 5.5 | 2.2 |

## Test steps
1. Enter `5.5` as the numerator.
2. Select the division operation.
3. Enter `2.2` as the denominator.
4. Submit the calculation.

## Expected result
The application displays the result `2.5`.

## Status / Related bugs
Not Run / None
