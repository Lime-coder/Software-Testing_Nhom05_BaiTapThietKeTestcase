# TC-DIV-003: Divide zero by a non-zero integer

## Requirement ID
FR-DIV-001

## Module / Test type / Technique
Division / Functional / Equivalence Partitioning

## Preconditions
- The application is open and ready to accept numeric input.

## Test Owner
Quốc Huy

## Test data
| Numerator | Denominator |
|---|---|
| 0 | 5 |

## Test steps
1. Enter `0` as the numerator.
2. Select the division operation.
3. Enter `5` as the denominator.
4. Submit the calculation.

## Expected result
The application displays the result `0`.

## Status / Related bugs
Not Run / None
