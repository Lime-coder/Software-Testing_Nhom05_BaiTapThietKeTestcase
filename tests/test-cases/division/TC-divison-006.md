# TC-DIV-006: Divide a positive numerator by a negative denominator

## Requirement ID
FR-DIV-001

## Module / Test type / Technique
Division / Functional / Equivalence Partitioning

## Preconditions
- The application is open and ready to accept numeric input.

## Test Owner
Quốc Huy

## Test data
| Numerator | Denominator |
|---|---|
| 8 | -2 |

## Test steps
1. Enter `8` as the numerator.
2. Select the division operation.
3. Enter `-2` as the denominator.
4. Submit the calculation.

## Expected result
The application displays the result `-4`.

## Status / Related bugs
Not Run / None
